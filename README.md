A make.fun entry for [Five Seconds to Explain the Glass](https://make.fun/competitions/u-po-pu-five-seconds-to-explain-the-glass-934d9949): the one sentence a house cat would say in its own defence in the five seconds after sweeping a glass off the table.

The cat's excuse, 59 characters:

> It was blocking my sunbeam, so I removed the obstruction.

Run it:

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --check    # validate against the 1-200 character gate
python3 main.py --self-test
python3 main.py --tournament
```
